Things i've built

Backend, media streaming and automation. Mostly Python, Java and TypeScript.

  • Melora.py A Discord music bot built to run unattended 24/7, with crash recovery, health watchdogs, sliding-window rate limiting and 171 unit tests checked by GitHub Actions. Python, discord.py, lavalink.py
  • Melora-Java The same music bot idea in Java: multi-threaded audio handling across many servers at once. Java, JDA, Lavaplayer
  • Melora.js A lightweight, typed audio bot with slash commands and fast playback start. TypeScript, Node.js
  • Online-Fix Tracker Polls an RSS feed, removes duplicates, translates Russian posts to English and sends them to Discord. Ships as a Docker container. Python, Docker
  • YTDL Toolkit A PowerShell wrapper around yt-dlp for choosing the video and audio formats you want. PowerShell, yt-dlp, FFmpeg
