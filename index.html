Projects

Audio infrastructure, automation and tools. All open source on GitHub.

  • Melora.py

    A Discord music bot built to run unattended. It has crash-recovery supervisors, health watchdogs and a sliding-window rate limiter, and 171 unit tests run on every push with GitHub Actions.

    Python, discord.py, lavalink.py

  • Melora-Java

    The same bot in Java, with multi-threaded audio handling across many servers at once.

    Java, JDA, Lavaplayer

  • Melora.js

    A lightweight, typed version with slash commands and fast playback start.

    TypeScript, Node.js

  • Online-Fix Tracker

    Polls an RSS feed, removes duplicates, translates Russian posts into English and sends them to Discord. Runs in Docker.

    Python, Docker

  • YTDL Toolkit

    A PowerShell front end for yt-dlp for choosing which video and audio formats to download.

    PowerShell, yt-dlp, FFmpeg

The three Melora versions are compared on the Melora site.
