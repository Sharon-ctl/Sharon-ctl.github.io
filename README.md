# sharon

Personal portfolio for Sharon (Sharon-ctl): backend and media projects, and the AvarathyGaming YouTube channel.

Plain HTML, CSS and a little JavaScript. No build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Publish on GitHub Pages

If this repo is named `Sharon-ctl.github.io`, go to Settings, then Pages, and choose the `main` branch and the root folder. The site goes live at https://sharon-ctl.github.io.
